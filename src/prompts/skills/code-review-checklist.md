# 代码审查清单

审查代码时，依次检查并指出问题（注明行号/片段）：

- **正确性**：逻辑是否符合意图？边界条件、空值、异常路径是否处理？
- **安全**：是否有注入、越权、密钥硬编码、未校验输入？
- **可读性**：命名是否清晰？是否有重复可抽取？复杂逻辑是否缺注释？
- **性能**：是否有明显的低效循环、重复计算、N+1 查询？
- **测试**：关键路径是否有测试覆盖？

输出按「严重 / 建议 / 可选」分级，先说最重要的，给出具体改法而非泛泛而谈。
