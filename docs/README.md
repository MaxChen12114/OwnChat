# docs/ · 项目物料

| 路径 | 用途 |
|---|---|
| `screenshots/*.png` | README 展示截图（玻璃主题 / 烛夜私语 / 设置面板） |

- `screenshots/chat-candle.png`、`social-preview.png`：*Stars and Milky Way over Åbyfjorden 8* —— **CC0**（via Wikimedia Commons）。
