# 设置页文案改写样板（B2 打样 · 2026-11-11 · v2 评审修订）

> 依据：`docs/ui-audit-20261111.md` 术语表；语气基准 Notion / Linear / Stripe：短句、结论先行、不解释显而易见的事、不安抚、不承诺。
> v2 修订：经文案评审复核，修回「省宾语/省定语」造成的歧义；标点统一全角。
> 用法：确认样板后按此批量改 `settings.js` / `index.html`；功能含义不改，疑问处标 `待确认`。

## 规则

1. 每条说明 ≤2 行；第 3 行起的信息移到 `<details>` 或 tooltip
2. 删掉安抚与说教：「请注意」「你会发现」「请放心」「仅本设备生效」→ 改「仅本机」
3. 标题中文为主：`访问码` 不写 `访问码（Auth）`，`云同步` 不写 `云同步（Cloud Sync）`
4. 术语：访问码 / API Key / 本机 / 会话 / 对话 / 渠道 / 上下文（**删除「本设备」**，统一「本机」）
5. 句子去掉括号补充；必要信息独立成句；标点全角

## 样板 1 · 设置副标题

- 现：`本地数据保存在浏览器；启用云同步后也会上传到你的 Cloudflare KV`
- 改：`数据默认存在浏览器；开启云同步后上传到你的 Cloudflare KV。`
- 说明：保留「浏览器」——清缓存会丢数据，这是用户决策信息；「上传」与云同步同义，不用「备份」。

## 样板 2 · 访问码卡

- 标题：`访问码（Auth）` → `访问码`
- 现：`云同步需要访问码（Cloudflare Secret CHAT_PASSWORD）。登录后，聊天请求会自动带上访问码；退出登录后按访客处理：需要使用你自己的模型渠道和 Key。`
- 改：`云同步需要访问码。登录后请求自动带访问码；退出后以访客身份使用你自己的模型渠道与 API Key。`
- 状态行：`访客模式 · 使用你自己的模型渠道与 API Key`

## 样板 3 · 本地记忆卡

- 标题：`本地对话记忆` → `本地记忆`
- 现：`开启后发消息会带上本机历史上下文，AI 能记住你们说过的话。仅本设备（不进云同步）。`
- 改：`发送时附带本机历史消息；不进云同步。`
- 开关一：`记住本机对话（带上历史消息）` → `发送历史消息`
- 开关二：`记住自定义提示词（每次对话带上）` → `追加自定义提示词`
- 黄条：`历史消息越多越费 token；过长时清空对话。`

## 样板 4 · 云同步卡

- 标题：`云同步（Cloud Sync）` → `云同步`
- 现：`把数据同步到 Cloudflare KV,换浏览器换设备都能看到:角色卡 / 指令模块 / 亲密度 / 费用日志,以及对话历史（需勾选下方「同步聊天历史」)。本地改动延迟 30 秒自动推送(为省 KV 配额;桌面端关窗与回到前台会立刻补推/补拉)。「立即上传」只推本机改动；「云端拉取」才拉其他设备的改动；启动/回前台/每 5 分钟也会自动拉。不同步:密码 token / 同步状态本身。`
- 改（正文 2 行）：
  `同步到 Cloudflare KV，换浏览器或设备都能看到角色卡、指令模块、亲密度与费用日志。`
  `会话记录需勾选「同步聊天历史」；改动 30 秒内自动上传。`
- 按钮差异移入 tooltip：
  `「立即上传」只推本机改动；「云端拉取」拉取其他设备；启动与回前台自动拉取。`
- 末句：`不同步：访问码与同步状态。`

## 样板 5 · 模型 API Key 提示

- 现：`Key 仅存本设备（云同步公开副本剥掉 Key）。`
- 改：`API Key 只存本机，不同步。`

## 术语与标点

- 删除「本设备」，统一「本机」
- 「会话 / 对话 / 聊天」三种叫法并存：建议**侧栏列表项 = 会话**；**一次交流 = 对话**；**功能名 = 聊天**
- 「换浏览器换设备」→「换浏览器或设备」
- 分组标题里的 `账号 / 数据 / 同步` 建议改为 `账号 · 数据 · 同步`（全角间隔号）
- 标点全部全角，禁止半角逗号/冒号混入中文

## 待确认（需所有者拍板，不擅自改）

1. 云同步开关是否改名：现「同步聊天历史」 vs 术语表建议的「同步会话」——改名会影响 i18n 词条与老用户认知。
2. 「对话记忆」 vs 「本地记忆」：样板取「本地记忆」，强调数据在本机。
3. 云同步卡的「立即上传 / 云端拉取」差异是否移入 tooltip（正文只留结论）。
