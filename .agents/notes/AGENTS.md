# AGENTS.md — Agent Notes

Agent Notes 本质上是由 agent 撰写的 RFC：持久的提案与决策记录，保留理由、备选方案、后果和所需的验证。遵循[文档标准](../../docs/AGENTS.md)与 [Agent Note 规则](README.md)。

**每一份新 Note 都要触发一次取代检查。** 在活动树里检索覆盖同一决策或同一机制的旧 Note，判断属于整体取代还是部分取代；判定为整体取代的 `implemented/` 条目，在**同一个 PR 内**移入 `archived/`。部分取代的保持活动，并双向交叉链接。

[`archived/`](archived/) 下的文件是冻结的历史快照：永远不要编辑，也不要当作当前权威。
